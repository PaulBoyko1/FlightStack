# Licensing

FlightStack is MIT licensed.  The repository does not vendor third-party source
or assets at this stage.

Permissive source references are recorded in the ecosystem audit.  Before a
dependency, copied file, model checkpoint, mesh, texture, or dataset enters the
repository, its license and any notice requirement must be checked separately.
In particular, a permissively licensed repository does not automatically grant
rights to every included asset.

GPL-only implementations are not copied into FlightStack.
